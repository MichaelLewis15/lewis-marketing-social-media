# Video styles (render_weekly.py "style")
Samples rendered from the ChatGPT Business Hub launch spec. `navy` is the original look: see `daily/launch/2026-11-11-chatgpt-business-hub/`.
- `light`  Clean: off-white page, navy type, highlighter accents, segmented progress bar
- `bold`   Color block: full-screen brand color wipes, giant numerals, kinetic titles
- `cards`  Cards: white cards popping onto navy and stacking as the points go by
Rotation order: navy -> light -> bold -> cards -> navy (never the same look twice in a row).
